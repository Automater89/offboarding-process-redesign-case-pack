# GitHub Copilot Prompts — Offboarding Process Redesign Case Pack

Use these in VS Code Copilot Chat or GitHub Copilot to accelerate documentation, requirements authoring, and artifact generation for this project.

---

## Project Planning

```
/plan Create a process redesign case pack for a cross-functional employee offboarding process. Break the project into phases: problem statement and stakeholder mapping, SIPOC, as-is process map and pain points, to-be design with AI and automation opportunities, user stories and acceptance criteria, RAID log, KPI framework, and executive summary.
```

---

## SIPOC Table

```
Create a SIPOC table for an employee offboarding process. Include columns for Supplier, Input, Process Step, Output, and Customer. Cover 6 to 8 key process steps from departure confirmation through HR record closure. Stakeholders include HR, IT, Security, Payroll, Manager, and the departing employee.
```

---

## User Stories

```
Generate 6 user stories and acceptance criteria for a redesigned employee offboarding workflow. Write stories from the perspective of: HR Business Partner, IT administrator, direct manager, Security administrator, Payroll, and departing employee. Each story should include: As a [role], I want to [action], So that [outcome]. Include 3 to 5 acceptance criteria per story as a checklist.
```

---

## RAID Log

```
Create a RAID log for an employee offboarding process redesign project. Include: 5 risks with likelihood (High/Medium/Low), impact (High/Medium/Low), and mitigation; 4 assumptions with owner and validation needed flag; 2 open issues with status and resolution path; 4 dependencies with what they depend on and risk if not met.
```

---

## KPI Framework

```
Create a KPI framework for measuring the success of a redesigned employee offboarding process. Include KPIs for: end-to-end cycle time, on-time access revocation, on-time badge deactivation, knowledge transfer completion, SLA breach rate, HR record closure rate, and automation trigger reliability. For each KPI include: definition, current baseline (unknown or estimated), target, and measurement source. Include a baselining plan and measurement cadence.
```

---

## Executive Summary Slide

```
Draft a concise executive summary for a process redesign presentation on employee offboarding. Include: the business problem (1-2 sentences), current-state pain points (3 bullets), future-state design summary (3 bullets), where AI and automation help (2 bullets), and the expected KPI improvements. Keep language plain and business-facing, not technical.
```
